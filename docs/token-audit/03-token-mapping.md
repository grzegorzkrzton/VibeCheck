**Purpose:** propose mappings for later parity review. This document does **not** decide whether tokens match.

Original Figma and code names/values are preserved in the first two columns. Normalization is comparison-only.

## Normalization rules (comparison only)

| Kind | Rule |
|---|---|
| Case | Lowercased for compare |
| Separators | `/`, spaces, `_`, `.` treated as `-` |
| Prefixes / namespaces | Strip `var(--vc-)`, `--vc-`, `VibeCheck/`, `Elevation/` for compare |
| Duplicate segments | Collapse repeated adjacent segments (`gray/gray-50`→`gray-50`, `bg/bg`→`bg`) |
| Badge shorthand | `pending - bg` / `success - bg` compared as `pending-background` / `success-background` |
| Color formats | HEX 3/6/8 and `rgb(0 0 0 / N%)` compared via sRGB + alpha |
| Units | Figma raw floats vs code `Npx` compared numerically |
| Opacity | Figma `45` vs code `0.45` compared as possible % vs unit interval (not assumed equal) |
| Font weight | `Regular`↔400, `Semi Bold`↔600, `Bold`↔700 |
| Alias syntax | Figma `VARIABLE_ALIAS` resolved to primitive HEX for evidence; code `var(--vc-…)` chains noted |
| Modes | `Light`↔`light`, `Dark`↔`dark`, Figma `Value`↔ code shared |

Similar names alone were **not** treated as equivalent without value, alias, category, or usage evidence.
